# 🐉 Jogo do Dragão

Um jogo simples de um **dragão voador** feito em **Godot 4** com gráficos em **3D**.

## 🎮 Sobre o Jogo

A ideia é simples: você controla um dragão que pode voar livremente pelo cenário 3D.  
O projeto está em fase inicial, focado em estabelecer a mecânica de voo e a movimentação do personagem.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| `W` / `↑` | Mover para frente |
| `S` / `↓` | Mover para trás |
| `A` / `←` | Mover para a esquerda |
| `D` / `→` | Mover para a direita |
| `Espaço` / `Enter` | Bater asas (impulso de voo) |

## 🛠️ Tecnologias

- **Engine:** [Godot 4](https://godotengine.org/) (GDScript)
- **Gráficos:** 3D — modelo `.glb` do dragão com câmera em terceira pessoa
- **Física:** `CharacterBody3D` com gravidade e impulso de voo

## 🚀 Como Rodar

1. Instale o [Godot 4](https://godotengine.org/download)
2. Clone este repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/JogoDragao.git
   ```
3. Abra o Godot 4, clique em **Import** e selecione a pasta do projeto
4. Pressione **F5** para rodar
